# 0000001. Use net11

- Status: Accepted
- Date: 2026-07-19

## Context

AdrTool is a small personal CLI project with no external users or production
deployment constraints, which makes it a good place to try out the newest
.NET runtime and C# language features as early as possible, rather than
waiting for a stable release. At the time of writing, .NET 11 is only
available as a preview SDK (`11.0.100-preview.3.26207.106`).

## Decision

Target `net11.0` in both `AdrTool/AdrTool.csproj` and
`AdrTool.Tests/AdrTool.Tests.csproj`, and pin the preview SDK version in
`global.json` with `"rollForward": "latestPatch"` so all contributors and CI
build against the same preview toolchain.

## Consequences

- We get access to the latest C# language and .NET runtime features as soon
  as they land in preview builds.
- The project depends on a preview SDK, which is less stable than an LTS or
  GA release: APIs can change or be removed before .NET 11 ships, and the
  preview SDK must be installed manually (it isn't bundled with most IDEs or
  CI images by default).
- `dotnet pack`/`dotnet tool install` consumers of the published `AdrTool`
  package will also require a compatible .NET 11 runtime once it's no longer
  preview-only, which may narrow the tool's installable audience until .NET
  11 reaches general availability.
- Once .NET 11 GAs, `global.json` should be updated to pin the released SDK
  version instead of the preview build.
